What protects a listed Chimpion

  • It never leaves your wallet. Listing freezes the NFT in place with the per-listing program address as its only delegate.
  • Nothing else can move it. Transfer, burn, approve, revoke, owner change and close are all rejected while frozen. We tried each one from the owner's wallet and through Token Metadata; all fail.
  • Swaps are all-or-nothing. Both NFTs and the fee move in one instruction or none do. The offered NFT must be a verified Chimpion the taker holds. Your fee split is locked when you list.
  • You can always exit. Delist works even when the board is paused. The admin can only return NFTs to their owners, never redirect them.
  • The program holds nothing. No vault, no custody, no pooled SOL. Fees pass straight to the treasury and the lister.

Verified against live data

  • 222 Chimpions on chain; 25 sampled across the collection are all legacy NFTs, verified members, with the freeze authority the program requires.
  • Treasury is a plain system wallet; program address unused before deploy.
  • Dependencies: zero known vulnerabilities (cargo audit).

The one trust point, and how it is held

  • Only a program upgrade could ever touch listed NFTs.
  • At launch the upgrade authority moves to a 5-of-9 Squads multisig by Safe Authority Transfer; no hot wallet keeps it.
  • Every upgrade is a vault-owned buffer anyone can verify byte-for-byte before members approve.
